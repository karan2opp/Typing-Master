# Word lists

`en.ts` and `hi.ts` are generated by `scripts/build-wordlists.mjs`. Each holds 10,000
words, most frequent first. Tests draw from the top 200, 1,000, 5,000 or 10,000
(the difficulty level). Do not edit them by hand; change the script and rebuild.

## Sources

| List | Built from | Cleaned with |
|---|---|---|
| English | Word counts from Peter Norvig, <https://norvig.com/ngrams/> (`count_1w.txt`), which are counts from the Google Web Trillion Word Corpus distributed by the Linguistic Data Consortium (LDC2006T13) | dwyl `words_alpha.txt` dictionary (The Unlicense, public domain); LDNOOBW English bad-words list (CC BY 4.0) used only to remove words; the short filters in the script |
| Hindi | Leipzig Corpora Collection, Hindi Wikipedia 2021 (100K sentences), <https://wortschatz.uni-leipzig.de/> | Structural check for valid Devanagari words; only characters the Inscript layout can type; a short blocked-words list in the script |

## Licensing: not settled for commercial use

**This needs a decision before the app is distributed beyond a non-commercial,
educational setting.** The words themselves are not the issue; the terms of the
data the lists were counted from are.

- **Hindi.** The Leipzig Collection's own terms of usage state its data is free for
  private and scientific use under **CC BY-NC** (non-commercial). Some third-party
  pages label it plain CC BY; the project's own page is the one to rely on. If it
  is used, cite: Goldhahn, Eckart & Quasthoff, *Building Large Monolingual
  Dictionaries at the Leipzig Corpora Collection: From 100 to 200 Languages*, LREC 2012.
- **English.** Norvig's page licenses his *code* under MIT. The *data* is derived from
  the Google corpus as distributed by the LDC, whose agreement is aimed at education
  and research. Commercial use is not clearly permitted.
- A list of the most frequent words is mostly facts, and lawyers differ on whether
  such a list is protected at all, but that is a legal question, not a technical one.

If the institute charges fees for the app or for classes that use it, either get
advice, or rebuild the lists from a source with clear terms. Options: Wikipedia text
(CC BY-SA 4.0, needs attribution and the list shared alike), or text in the public
domain. The build script only needs a word-frequency file per language, so a new
source is a small change.

## Review before use with students

- **Hindi** is built from Wikipedia alone (the news corpus did not download), so it
  leans formal and includes place and person names. Have a Hindi speaker read it.
- **Blocked words** (`HINDI_BLOCKED` in the script) are a short, conservative list.
  It is not a substitute for a native reader's review.
- **English** keeps web-flavoured words (`home`, `page`, `menu`) and some names
  (`jordan`), which is normal for lists counted from the web.
